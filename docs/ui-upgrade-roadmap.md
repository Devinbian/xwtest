# 官网 UI 升级需求罗盘

## 目标与边界

官网用于品牌展示与引流，客户通过电话或微信联系。升级聚焦大气、科技感、吸引力与清晰易读，不增加复杂业务功能。

## 当前统一方向

按最新反馈保留原先绿色与白色的配色体系，不采用黑色或浅灰作为整站主题。以原品牌绿 `#83b735` 为核心，白色为主要内容背景；同色系深绿用于可读文字、按钮与绿色展示面板，浅绿用于光场、边线和卡片层次。产品和品牌图片保持原色。

- 全站颜色集中于 `src/styles/_variables.scss`；导航、首页板块、页脚、内页横幅、咨询弹窗使用同一套绿色层级。
- 导航恢复白底及原绿色 Logo；主营产品、合作品牌回到白色内容区；热门产品使用绿色展示区与白色设备卡片；内页横幅和联系面板共享绿色渐变。
- 保留放大的字级：正文 16–18px，导航 18px，首屏标题最大 104px，产品卡片标题 20px。核心内容最大宽度 1600px。
- 科技感来自真实设备主视觉、测量网格与用途相关的演示动画，避免仅用换色表达升级。

## 三个方向

| 方向 | 本轮落地 |
| --- | --- |
| 整站视觉统一 | 绿色与白色贯穿导航、内容区、卡片、按钮、内页和页脚；移除上一版石墨黑与银灰主视觉 |
| 仪器测试动效 | 首页三屏分别显示波形采集、影像测量定位、光学扫描；均标明动态演示，不冒充真实测量数据 |
| 大气与精致 | 保留大标题与大设备图，统一边线与绿色层次，减轻卡片黑色阴影，保持长名称可换行 |

## 动效行为

SVG/CSS 动效无新增依赖。暂停按钮同时控制首屏轮播和测试动画；不可见幻灯片、首屏离开视口、页面进入后台时停止测试动画；尊重系统减少动态效果偏好。鼠标悬停或键盘焦点在首屏时只暂停自动换页，测试演示可继续。

- Node 22.21.1：生产构建、类型检查、两个 code-health 检查、`git diff --check` 通过。
